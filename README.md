Slay Nails — Nail Services Booking System

Community Problem
In Ipil, Zamboanga Sibugay, a working-student nail technician and her local clients struggle to coordinate nail service appointments around class and work hours because service prices and vacant time slots are tracked manually through chat messages, leading to slow replies and double-booked slots. A web page where the owner and customers can view offered nail services with prices, post vacant date and time slots, and book unreserved slots that lock once taken helps prevent double-bookings and saves time.

Functional Requirement (FR-01)
FR-01: The nail technician (owner) and customers can manage and book nail appointments: offered nail services with prices, owner-inputted vacant date and time slots, and customer bookings (customer name, selected service, and slot) where booked slots immediately become unclickable.

How to Run
Open "index.html" directly in any modern web browser. All slot and booking data is stored locally in the browser using "localStorage" (no server or database required). Demo uses fictional client names only (RA 10173).
